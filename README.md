# 🛡️ GeoShield

## Smart Account & Device Security Monitor

GeoShield is a cybersecurity academic project designed to demonstrate
how authorized account activity, device activity, location sharing and
suspicious security events can be monitored through a web dashboard.

---

## 🚀 Features

- User login
- Security dashboard
- Authorized browser location sharing
- Interactive map
- Security event monitoring
- Suspicious activity detection
- Device activity monitoring
- Risk classification
- Security score
- Demo security event generation
- SQLite database
- Responsive user interface

---

## 🛠️ Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap
